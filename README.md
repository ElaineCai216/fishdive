# FishDive 🐟 · 专注养鱼

Forest 式专注计时 + 鱼收集养成。选择专注事项 → 设定时长 → 专注计时 → 完成获得随机鱼 → 收进专属鱼塘，逐步集齐 24 种鱼的图鉴。

## 功能

- **专注**：自由输入任务名（可存为常用任务）；预设时长（15/25/45/60/90 分钟）+ 自定义滑杆（5–180 分钟）；计时基于结束时间戳，切换标签页/后台不失效；专注中鱼卵逐渐长大
- **得鱼规则**：专注越久鱼越稀有（分档概率），完成后水花揭示所得鱼
  - 5–24 分钟：常见 100%
  - 25–44 分钟：常见 70% / 稀有 30%
  - 45–59 分钟：稀有 65% / 史诗 35%
  - 60+ 分钟：史诗 80% / 传说 20%
- **鱼塘**：自由水族箱，鱼自动游动、可拖动摆放；同种鱼可多条共存
- **图鉴**：24 种鱼 / 4 档稀有度（常见 12 / 稀有 8 / 史诗 3 / 传说 1），未获得显示剪影
- **统计**：今日/本周时长与次数、连续专注天数、按任务聚合排行、日历热力图、近 30 天趋势图
- **设置**：完成音效开关、导出/导入 JSON 备份
- 中途放弃：不给鱼、无惩罚

## 使用

```bash
npm install
npm run dev      # 本地开发
npm test         # 单元测试（稀有度抽样 / 统计计算）
npm run build    # 产物在 dist/
```

## 数据

所有数据保存在浏览器 `localStorage`（key `fishdive:v1`），不上传服务器；换设备不自动同步，建议定期在「设置」里导出备份。

## 部署

推送到 GitHub 后，`.github/workflows/deploy.yml` 会自动构建并发布到 GitHub Pages（仓库需开启 Pages 的 GitHub Actions 源）。

## 技术

Vite + 原生 JavaScript（零框架）、Vitest 单元测试、参数化 SVG 鱼渲染（24 种鱼由一份模板 + 配色/花纹参数生成）、Web Audio 合成音效。
